FIFA World Cup 2026 — Retro Table Layout

A retro-style website developed for an academic project about the 2026 FIFA World Cup, focused on practicing basic HTML concepts and recreating the visual style of early websites.

About the Project:

The website presents information about the 2026 FIFA World Cup, including:

- Competition information
- Favorite teams to win the title
- World Cup stadiums
- Host countries
- Interesting facts
- Partners
- Useful links

Technologies & Requirements:

This project follows the restrictions established for the assignment:

- Pure HTML
- No CSS
- No JavaScript
- Images and hyperlinks integrated into the pages
- Hosted with GitHub Pages
  
The design intentionally follows the visual style of 1990s and early 2000s websites, using tables as the main layout system.
